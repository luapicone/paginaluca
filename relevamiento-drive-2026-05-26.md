## Metodo de profundizacion

Esta version profundiza el relevamiento archivo por archivo usando solo evidencia verificable extraida del material descargado. Se trabajo con: transcripcion completa de audio para todos los videos, metadata tecnica de cada asset y extraccion de texto para todos los PDFs.

Reglas de lectura aplicadas en este documento:

- `audio del video`: todo lo que aparece en esas subsecciones sale de la transcripcion real del archivo.
- `texto del PDF`: todo lo que aparece en esas subsecciones sale de `pdftotext` sobre el PDF real.
- `limite verificable`: cuando el PDF no tiene capa de texto o el texto es minimo, se explicita y no se rellena con supuestos.

## Resumen del set

- `50` archivos visibles contando `.DS_Store`.
- `16` videos procesados con transcripcion completa.
- `33` PDFs procesados con extraccion de texto.
- El set es una biblioteca de referencia para funnels, e-commerce, captacion de leads y paginas de conversion, no un repositorio juridico ni institucional.
- El audio de los videos funciona como una clase o walkthrough: explica para que sirve cada wireframe, que poner above the fold, como ubicar CTA, social proof, formularios, comparativas y cierres de conversion.
